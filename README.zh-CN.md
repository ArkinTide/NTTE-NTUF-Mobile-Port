# Nuclear Throne: NTTE + Uncharted Frontier — Mobile Port

NTTE 与 **Uncharted Frontier（NTUF）1.0.3.3** 的 Android／iOS 移植源码，
保留 Undergrowth、Details+ 和简体中文。当前版本 **2.1.4**，内部构建 **109**。

从 [MEGA 下载文件夹](https://mega.nz/folder/PfIDSaSZ#ZcRokP34or9J0JofsIgrEA) 获取 APK／IPA，并核对同目录的
`SHA256SUMS-NTTE-NTUF-2.1.4.txt`。GitHub 仅分发文本源码及版本说明；
iOS 安装包需要重新签名。见 [2.1.4 说明](docs/RELEASE-2.1.4.md)。

## 2.1.4 build109 — 近战、触屏与兼容性维护

当前重新编译的最终 Windows VM／输入通过 37 项明确列出的原生专项，
另有 190 项 Python 检查日志经哈希核验。旧 VM 的通过数不计入本次验收。
具体场景和结果见[本次验证摘要](docs/validation/2.1.4-development-regression.json)。

1. 复核本轮测试的17把 NTTE／NTUF 近战武器（10把 NTUF 和7把选定 NTTE 武器）及其融合前端的长臂加成，当前维护源与最终 Windows VM 未复现报告中的失效，不把原有加成公式描述为新增修复。普通骨镰刀经真实变异选择后，在目标间距为4像素的测试网格上，最远受伤目标的原始中心距离在30Hz为40→60像素、60Hz为44→60像素，重击均为56→80像素；这些数值描述所采样的靶心距离。切换形态、换武器及续局路径也通过本轮验证。

2. 修正豪宅黄金兑换站局部变量和转场螺旋预热问题；七张截图所涉的失效墙体引用、稀疏设置重置、已销毁追踪目标及自定义数据作用域创建实例的原有防护，也在当前最终 VM 中重新执行验证。

3. 手术变异的中文说明按实际字体高度换行并增加行距，标题与说明各自测量，避免中文文字叠在一起。

4. 机器人重启页面使用独立 GUI 相机绘制 YES／NO，并在原有选项出现时间之后恢复缺失按钮；确认选择后不重复创建或提交。

5. 优化高频弹幕家族的实体类型、数量与存在性查询，减少重复建立完整实体列表。差分测试检查旧实现的返回值、类型及非法输入行为；本轮不作手机帧率承诺。

6. 移除骨镰刀形态按钮右上角的额外白色箭头，保留武器图标、形态按钮及原有切换功能。

7. 对齐鹦鹉和泡泡角色偏好设置的图标、文字与开关列，给开关保留间距，并按可用宽度缩放长文本。

8. 触屏移动增加连续方向与小幅操作处理，检查原始触点输入、摇杆死区以及30／60Hz下相同时间的响应。

Android versionCode 3000109，保留应用标识和签名，并核验 16KB 布局；
iOS build 109 需要重新签名。iOS 使用新编译游戏数据及保留的原生 Runner，
没有新的 Mac 原生编译。GAME_BUILD／存档协议仍为 3004。

本轮八项要求的结论逐项列于上方，专项覆盖近战长臂复核、七图崩溃路径、
手术中文排版、机器人重启选项、实体查询性能、骨镰刀按钮、角色偏好列对齐和触屏移动。
原有地图、存档、角色与内容专项在同一最终 VM 中重新执行，旧通过记录不充作新结果。
未知随机地图与所有武器组合尚不能作整体保证。
后台静音桌面测试不能证明手机混音或帧率；未进行 Android／iOS 真机、
完整随机战役或所有设备帧率验收。
