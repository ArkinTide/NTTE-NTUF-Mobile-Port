NTTE 与 **Uncharted Frontier（NTUF）1.0.3.3** 的 Android／iOS 移植源码，
保留 Undergrowth、Details+ 和简体中文。当前版本 **2.1.3**，内部构建 **108**。

从 [MEGA 下载文件夹](https://mega.nz/folder/PfIDSaSZ#ZcRokP34or9J0JofsIgrEA) 获取 APK／IPA，并核对同目录的
`SHA256SUMS-NTTE-NTUF-2.1.3.txt`。GitHub 仅分发文本源码及版本说明；
iOS 安装包需要重新签名。见 [2.1.3 说明](docs/RELEASE-2.1.3.md)。

## 2.1.3 build108 — 区域生成、泡泡攻击与性能修复

当前重新编译的最终 Windows VM／输入通过 32 项明确列出的原生专项，
另有 160 项 Python 检查日志经哈希核验。旧 VM 的通过数不计入本次验收。
具体场景和结果见[本次验证摘要](docs/validation/2.1.3-development-regression.json)。

修复区域数据回调读取不存在的实例id、追踪弹目标消失、冲击无人机判定框失去主人后销毁，以及稀疏设置分类重置导致的报错。海滩区域球新增地块若岸边完全封闭，会仅在本次新增墙体上打开入口；终极解密地块被地面重建替换后保留原坐标、外观和交互，并复验钥匙顺序、清怪门禁、合成、交付与奖励流程。

修复大苍蝇发射的蛆虫重复落地生成及死亡后再生成；诅咒武器箱排除任务骨头。泡泡手动瞄准回到摇杆死区再松手时保留最后有效攻击方向，两种初始武器及技能开关均可正常触发；超出取消区域的手势仍按原规则取消。

轮廓／血条颜色页面新增默认开启的“同时更换准心颜色”，关闭后准心恢复白色，涵盖桌面、手柄及触屏准心。固定普通菜单旋涡互补遮罩的取样，修复60帧背景闪烁并保留其他传送门动画。

自动降帧取消固定周期强行升回60帧，改为达到持续CPU处理余量后恢复；恢复尚未连续稳定5秒便再次过载时，会在本关保持30帧以防反复切换。进入新关卡、返回菜单或关闭自动降帧后重新评估，暂停保留保护，连续稳定5秒才接受恢复；按真实继承的Alarm槽补偿计时，减少无用扫描；类行星加农炮融合近战射线先筛选扫掠范围，再执行原有精确碰撞。上述共享路径同时用于新增地图和内置困难模式；未作Android／iOS真机帧率或所有随机闪退已经消除的保证。

Android versionCode 3000108，保留应用标识和签名，并核验 16KB 布局；
iOS build 108 需要重新签名。iOS 使用新编译游戏数据及保留的原生 Runner，
没有新的 Mac 原生编译。GAME_BUILD／存档协议仍为 3004。

本轮场景由当前需求清单与最终专项列表明确限定，涵盖区域球道路、对象生命周期、泡泡攻击、终极解密、准心颜色、自动帧率与融合射线。
未知随机地图与所有武器组合尚不能作整体保证。
后台静音桌面测试不能证明手机混音或帧率；未进行 Android／iOS 真机、
完整随机战役或所有设备帧率验收。
