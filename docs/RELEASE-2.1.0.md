# NTTE + NTUF 2.1.0

本次更新修正无人机的友军弹幕碰撞和密集拦截开销、红水晶洞窟异常墙体、风暴王冠锁定轮廓，以及甲虫的“打开秘密宝箱”解锁提示。

加入默认开启的 NTUF、Undergrowth 独立内容开关。NTUF 关闭时其余 NTUF 设置变灰；游戏进行中两个开关均不可操作，只能在主菜单或选人界面修改。续局沿用原局保存的内容状态。

NTUF 蓄力武器显示 NTTE 风格蓄力条。开启控制台、练习模式或自定义模式的本局无法解锁成就，续局继续保留此限制。天气音乐在触发当关播放。

Fixes drone allied-fire collisions and dense interception overhead, Red Caves walls, the Storms locked silhouette, and the Beetle unlock translation. Adds independent default-on NTUF/Undergrowth content switches, disabled during live runs; NTUF settings grey out when the pack is off. Continue retains saved content. Adds NTUF charge bars, persistent achievement exclusion for console/practice/custom runs, and same-room weather music.

安装包：[MEGA 下载文件夹](https://mega.nz/folder/PfIDSaSZ#ZcRokP34or9J0JofsIgrEA)。GitHub 仅提供文本源码。

版本 2.1.0，内部构建 105。Android 保留签名与应用标识，iOS IPA 需要重新签名。存档协议保持 3004。Hardmode 未修改。

验证范围是当前最终 Windows VM 的 28 项后台静音专项和维护工具检查；未进行 Android／iOS 真机、完整随机战役或所有设备 60 FPS 验收。

修正首个候选包反馈：两个内容开关在真实设置界面中生效，开关后其余 NTUF 设置立即刷新。玩家火药桶粉碎锤蓄力弹及落地火药保留友军识别。机器人完成网络空间后可返回正常关卡，兼容恢复旧续局的返回区域。控制台局不能新增永久解锁或保存黄金武器；自定义模式的 NTTE／NTUF 解锁和统计独立保存到各自槽位，成就和黄金武器仍受限制。甲虫选人提示为“打开秘密宝箱”。
