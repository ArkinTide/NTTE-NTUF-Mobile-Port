# NTTE + NTUF 2.1.7 · build 112

## 简体中文

- 修复奖励王冠、罪恶王冠、红晶王冠和风暴王冠的选用与解锁。开启「解锁王冠」后，自定义模式可装备这四顶王冠，所选王冠按槽位保存。普通模式可按原条件解锁。只在选人界面开关控制台或查询信息，仍可在下一局解锁王冠。
- 普通和诅咒水晶蜘蛛下落期间会持续显示下落贴图，落地后恢复原有动画。

Windows VM 的七项回归测试通过，覆盖 30 和 60 帧下的王冠解锁、存档重载、自定义开局与蜘蛛绘制。此次未进行 Android 或 iOS 真机测试。Android 保留应用标识和签名，版本代码为 3000112。iOS build 112 需要重新签名。存档格式仍为 3004。

## English

- Crown of Bonus, Crown of Crime, Red Crown, and Crown of Storms can be equipped in Custom mode with Unlock Crowns enabled. Crown selections are saved per slot. The original Normal mode unlock requirements still apply. Opening then closing the character-select console or running a read-only query leaves the next run eligible for unlocks.
- Normal and cursed Crystal Spiders show the descent sprite throughout the fall and resume their regular animation after landing.

Seven Windows VM regression tests passed, covering crown unlocks, save reloads, Custom starts, and spider rendering at 30 and 60 FPS. No physical Android or iOS device was tested. Android retains the application identity and signing certificate with versionCode 3000112. iOS build 112 requires re-signing. The save format remains 3004.
