# NTTE + NTUF 2.1.2 / build107

修正红水晶洞窟隐藏小路旁的墙体堵住普通道路；机器人重启YES/NO在GUI最上层显示并保持缩放后的点击区域一致。修复近战碰墙时偶发崩溃，按实际字体测量重新排版警局IDPD变异提示。视频设置增加默认开启的自动降帧选项，并保持切换帧率后的运动与计时单位。泡泡角色偏好改为按下技能后同时进行武器攻击和泡泡攻击。

本轮通过同一构建的21项后台静音运行回归、96组红水晶洞窟生成样本和157项脚本检查。红洞验证保留普通道路、真实隐藏入口、岩石与往返通行。
APK保留应用标识与签名，Android versionCode3000107；IPA build107需要重新签名。存档协议仍为3004。
后台静音桌面专项无法代替手机真机、完整随机战役或所有设备帧率验收。Hardmode与Steam未修改。
